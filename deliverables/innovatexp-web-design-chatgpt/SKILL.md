# InnovateXP website design

Use this skill when designing, reviewing, or editing innovatexp.co pages or related campaign landing pages.

## Working approach

1. Inspect the existing page, navigation, assets, content, and mobile layout before changing anything. Identify the page's primary visitor question and one main action.
2. Work from the existing InnovateXP identity. Use a quiet editorial style: warm ivory backgrounds, dark ink text, subtle brass accents, generous spacing, hairline dividers, and restrained motion. Do not imitate luxury brand trademarks or layouts.
3. Use one font family per language across headings, body, forms, and navigation: Noto Serif TC for Traditional Chinese, Bodoni Moda for English and German, Shippori Mincho for Japanese. Keep fallback stacks only for missing glyphs.
4. Organize each page so a visitor or AI agent can identify the service, intended customer, process, deliverable, proof, and next action from semantic headings and concise text. Use one H1, descriptive links, accessible forms, and responsive layouts.
5. Use genuine InnovateXP assets and verified facts. Never invent customer sectors, partners, savings, outcomes, testimonials, prices, or availability. If working in the website repository, `docs/claims.md` is the authority for public numerical, client, and result claims; only publish rows marked VERIFIED.
6. Check desktop and mobile renders, keyboard focus, contrast, loading state, and form completion. Fix visible friction before delivery. Explain what changed and any remaining uncertainty.
