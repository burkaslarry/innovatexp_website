# AI 短片製作：收款流程建議

狀態：建議方案，尚未建立或連接付款帳戶。2026-10-11。

## 起步方案

使用公司 Stripe 帳戶建立每單獨立 Payment Link，配合公司銀行轉帳／轉數快（以銀行戶口實際支援為準）。網站先收 brief，按項目報價；客戶批准後才收到對應金額的付款連結。

1. 收 brief，列明鏡數、秒數、素材、交付版本、兩輪小改、重生成配額、平台費及日期。
2. 客戶書面接受報價及取消／退款條款。
3. 發出訂金付款連結（報價總額 50%），附項目編號及報價單。
4. 在 Stripe Dashboard 確認付款成功，記錄付款及報價編號。不要單憑付款截圖開工。
5. 完成分鏡／試鏡確認，製作及交有浮水印預覽。
6. 完成驗收後發尾款付款連結（剩餘 50%）。
7. 確认尾款後交無浮水印 master；保存交付及客戶確認記錄。
8. 額外修改先確認追加報價，再發新付款連結。

每單使用固定金額，不開啟客戶自行輸入金額。用自訂欄位收集項目／報價編號；收到付款後停用該項目連結，避免重複支付。平台對停用及完成付款次數限制的選項，以 Dashboard 實際提供為準。

## 手續費

Stripe 香港標準本地卡費用：3.4% + HK$2.35／成功交易。HK$3,000 訂金約 HK$104.35。海外卡、匯兌、Invoicing 或其他附加產品可能有額外費用，確認後才啟用。

來源：
- https://stripe.com/en-hk/pricing
- https://stripe.com/en-hk/payments/payment-links

## 開戶準備

準備公司及商業登記資料、帳戶代表／受益人核實資料、公司銀行戶口、網站、客服聯絡方式、服務說明，以及取消／退款政策。Stripe 實際核實要求以開戶時顯示為準。

## 下一階段

接單量增加後，再用 Stripe Checkout + webhook 自動更新訂金／尾款狀態及寄確認信。Webhook 要驗證簽署、防止重複處理，並以付款事件而非瀏覽器返回頁作付款依據。未完成設定前，網站不展示已可使用的付款按鈕。
